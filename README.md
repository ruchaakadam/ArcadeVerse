# 🎮 ArcadeVerse

## Play. Compete. Repeat.

ArcadeVerse is a browser-based arcade gaming website featuring a collection of classic, puzzle, reflex, and action games — all brought together in one fun and interactive platform.

The project is built using **HTML, CSS, and JavaScript** and is designed to run directly in a web browser without requiring any downloads or installations.

---

## 🕹️ Games

ArcadeVerse currently includes **10 playable games**:

| Game | Category | Difficulty |
|---|---|---|
| ❌⭕ Tic Tac Toe | Multiplayer / Puzzle | Easy |
| 🐍 Snake | Arcade / Reflex | Medium |
| 🧠 Memory Game | Puzzle | Easy |
| 🔢 2048 | Puzzle | Medium |
| 🧱 Breakout | Arcade / Reflex | Medium |
| 🐦 Flappy Bird | Arcade / Reflex | Hard |

| 🏓 Pong | Arcade / Multiplayer | Hard |
| 💣 Minesweeper | Puzzle | Hard |
| 🚀 Space Shooter | Arcade / Reflex | Hard |

- 🎮 10 playable browser games
- 🔎 Search games from the homepage
- 🏷️ Game category filters
- ⭐ Featured game section
- 🏆 High-score system in selected games

- ✨ Floating animated game emojis
- 🎨 Modern arcade-style interface
- 🧠 Puzzle and strategy games
