# 🎮 ArcadeVerse

> A fun, interactive browser-based arcade featuring classic games built with HTML, CSS and JavaScript.

---

## 🎯 About the Project

ArcadeVerse is an offline-friendly web arcade where users can play multiple classic games directly in their browser.

The project was created to practice and demonstrate front-end web development, JavaScript game logic, DOM manipulation, responsive UI design, and browser-based storage.

---

## 🕹️ Games

| Game | Description |
|------|-------------|
| 🎯 Tic-Tac-Toe | Classic two-player strategy game |
| 🐍 Snake | Control the snake, collect food and beat your high score |
| 🧠 Memory | Test your memory by matching pairs |
| ✊ Rock Paper Scissors | Classic game against the computer |
| 🔢 2048 | Combine numbered tiles and reach 2048 |

---

## ✨ Features

- 🎮 Multiple playable games
- 📱 Responsive user interface
- 🏆 High-score tracking
- 🔊 Game sound effects
- 🎨 Custom game-specific UI
- ⚡ Fast and lightweight
- 🌐 Runs directly in the browser
- 💾 Local browser storage for high scores

---

## 🛠️ Technologies Used

- **HTML5** — Structure and game pages
- **CSS3** — Styling, layouts and responsive design
- **JavaScript** — Game logic and interactivity
- **Canvas API** — Used for the Snake game
- **LocalStorage** — Used for storing high scores
