# 🎮 ArcadeVerse

ArcadeVerse is an interactive web-based arcade featuring a collection of classic games built using HTML, CSS, and JavaScript.

## 🎯 Games

- 🎯 Tic-Tac-Toe
- 🐍 Snake
- 🧠 Memory
- ✊ Rock Paper Scissors
- 🔢 2048

## ✨ Features

- Clean and responsive user interface
- Multiple playable games
- Score tracking and high scores
- Game sounds
- Simple and lightweight design
- Works directly in the browser

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas
- Local Storage

## 🚀 How to Play

Visit the live ArcadeVerse website and choose a game from the **Games** section.

No installation is required.
