# 🎮 ArcadeVerse

ArcadeVerse is a browser-based collection of classic games built with **HTML, CSS and JavaScript**.

## ✨ Features

- 🎮 Tic Tac Toe
- 🐍 Snake with score and high-score tracking
- 🧠 Memory matching game
- 🔎 Game search
- 🗂️ Category filtering
- 📱 Responsive layouts
- 💾 Snake high score saved with `localStorage`
- 🚫 No sign-up required

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API
- Local Storage

## ▶️ How to Run

Open `index.html` in a browser and start playing.

No framework or server is required for the games.
